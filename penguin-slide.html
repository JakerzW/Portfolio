Penguin Slide

Walder Games

Creator
Feb 2026 - Present
Android & Web

Description

An arcade ice puzzle game built in Unity. Navigate maze-like frozen ponds where momentum is everything — once you slide, you don't stop until you hit an obstacle!

Designed, developed and self-published independently, this project demonstrates my end-to-end solo game development capabilities.

Implementation Details

  • Programmed all gameplay controllers, mechanics, physics, menus and level infrastructure in Unity using C#.
  • Crafted all visual assets, user interface layouts, sprite sheets and character designs using Aseprite.
  • Composed and produced the original soundtrack and all sound effects using Ableton.
  • Utilised Antigravity coding tools to optimise and accelerate programming development.
